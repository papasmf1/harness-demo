# 파이썬 기초 특강 — 안전 점검 체크리스트

> 행사일: 2026년 5월 31일 (토) 오후 2시 | 장소: 아파트 커뮤니티센터 (실내) | 참가자: 최대 10명

---

## 1. 전날 점검 (2026-05-30)

- [ ] 커뮤니티센터 현장 답사 — 비상구 위치 직접 확인 및 동선 파악
- [ ] 소화기 위치 확인 (최소 1개, 강의실 내·복도 중 가까운 쪽)
- [ ] 전원 콘센트·멀티탭 수량 및 배치 위치 사전 파악 (과부하 여부 확인)
- [ ] 구급함 준비 완료 — 반창고, 소독제, 붕대, 냉찜질팩, 진통제 포함
- [ ] 손 소독제 2개 준비 완료
- [ ] 일회용 마스크 5장 이상 준비 완료
- [ ] 비상 연락처 카드 출력 (119, 112, 관리사무소, 주최자) — 안전 담당자 지참용
- [ ] 케이블·연장선 상태 육안 점검 (피복 손상·꺾임 여부)
- [ ] 참가자 중 알레르기·지병 보유자 사전 파악
- [ ] 강사 당일 컨디션 확인 (불참 시 취소 조건 해당)
- [ ] 커뮤니티센터 관리사무소에 행사 신고 및 비상 절차 문의

## 2. 당일 아침 점검 (2026-05-31, 행사 시작 전)

- [ ] 비상구 위치 재확인 — 퇴장 동선 장애물 없는지 점검
- [ ] 소화기 접근 가능 여부 재확인 (물건으로 가려지지 않았는지)
- [ ] 멀티탭·연장선 배치 완료 — 통행 동선과 겹치지 않도록 테이프 고정
- [ ] 노트북 및 장비 발열 상태 확인 후 통풍 공간 확보
- [ ] 구급함 위치 안전 담당자·보조 진행자와 공유
- [ ] 비상 연락처 카드 강의실 내 게시 (강사 테이블 또는 출입문 근처)
- [ ] 의자·테이블 배치 — 비상구 통로 최소 1m 이상 확보
- [ ] 공기 환기 상태 확인 (창문 또는 환기 시스템 작동 여부)
- [ ] 참가자 인원 10명 초과 입장 차단 — 등록·안내 담당자에게 재공지
- [ ] 음수대 또는 생수 비치 위치 확인
- [ ] 와이파이 공유기·포켓 와이파이 발열 가능성 — 통풍 위치에 배치
