# 파이썬 기초 특강 — 행사 기본 규칙

> 참가를 확정하신 분께 공유되는 안내 문서입니다. 행사 당일 전에 꼭 읽어 주세요.

## 1. 행사 개요

| 항목 | 내용 |
|------|------|
| **행사명** | 파이썬 기초 특강 |
| **날짜** | 2026년 5월 31일 (토요일) |
| **시작 시간** | 오후 2시 |
| **장소** | 아파트 커뮤니티센터 (실내) |
| **예상 인원** | 10명 이하 |
| **테마** | 프로그래밍 입문 교육 (동네 주민 대상) |

이 특강은 파이썬을 처음 접하는 분들을 위한 입문 교육입니다. 코딩 경험이 전혀 없어도 참가할 수 있으며, 실습 위주로 진행됩니다.

---

## 2. 참가 조건

- **사전 신청 필수:** 현장 접수는 받지 않습니다. 반드시 사전에 신청을 완료하신 분만 입장 가능합니다.
- **대상:** 아파트 주민 누구나 (코딩 경험 무관)
- **노트북 지참 권장:** 실습 참여를 위해 개인 노트북 지참을 강력히 권장합니다.
  - 노트북이 없으신 경우 사전에 주최자에게 알려 주세요. 가능한 범위에서 조율합니다.
  - 사용 가능한 OS: Windows, macOS, Linux 모두 가능
- **소프트웨어 사전 설치 권장:** 원활한 실습을 위해 행사 전 파이썬(Python 3.x)을 미리 설치해 오시면 좋습니다. 설치 방법은 주최자에게 문의해 주세요.
- **정원:** 선착순 10명으로 제한합니다. 정원 초과 시 대기 명단에 안내합니다.

## 3. 시간 규칙

| 구분 | 시각 |
|------|------|
| **입장 시작** | 오후 1시 40분 |
| **입장 마감** | 오후 2시 10분 |
| **특강 시작** | 오후 2시 (정각) |
| **예정 종료** | 오후 4시 (2시간 진행) |

- 오후 2시에 강의를 시작합니다. 늦게 입장하실 경우 진행 중인 실습에 합류하기 어려울 수 있으니 **10분 전까지 입장**해 주세요.
- 부득이하게 늦으실 경우 조용히 입장해 주시고, 주최자에게 사전에 알려 주시면 감사합니다.
- 일찍 퇴장하셔야 할 경우에도 사전에 주최자에게 알려 주세요.

## 4. 날씨 및 취소 방침

본 행사는 **실내**에서 진행되므로 비·눈·강풍 등 기상 조건에 따른 취소는 원칙적으로 없습니다.

**행사가 취소되는 경우는 다음과 같습니다:**

- 장소(커뮤니티센터) 측의 사정으로 시설 사용이 불가한 경우
- 강사 또는 주최자의 불가피한 사유 (건강, 긴급 상황 등)
- 참가 확정 인원이 3명 미만일 경우 (최소 인원 미달)
- 자연재해·재난 등 불가항력적인 상황

**취소 시 안내 방법:**

- 취소가 결정되면 **행사 당일 오전 11시까지** 신청자 전원에게 개별 연락드립니다.
- 취소 후 일정은 재협의하여 별도 공지합니다.

## 5. 금지 사항

원활한 교육 환경을 위해 아래 사항을 지켜 주세요.

- **음식물 섭취 금지:** 음료수를 포함한 모든 음식물은 강의 중 섭취를 삼가 주세요. (커뮤니티센터 내부 규정)
- **강의 중 통화 금지:** 입장 전 휴대폰을 무음 또는 진동으로 전환해 주세요. 긴급 상황 시 조용히 퇴장 후 통화해 주세요.
- **무단 녹화·녹음 금지:** 강의 내용의 녹화·녹음은 사전 허가 없이 금지합니다.
- **대리 참가 금지:** 사전 신청자 본인만 참가 가능합니다.
- **시설 파손 주의:** 커뮤니티센터 비품 및 시설을 소중히 사용해 주세요.
- **강의 중 타 업무 자제:** 개인 업무나 강의와 무관한 화면 사용은 삼가 주세요. 다른 참가자에게 방해가 될 수 있습니다.
