## 학습 방식

**추천: 온라인 강의**  
예산 적합성·시간 유연성·체계적 커리큘럼 3가지 이유로 선택.

| 방식 | 월 비용 | 피드백 | 유연성 | 판정 |
|---|---|---|---|---|
| 독학 | 0원 | 없음 | 매우 높음 | 나쁜 습관 위험으로 비권장 |
| 학원 | 6~12만원 | 즉각적 | 낮음 | 예산 초과 가능 |
| **온라인 강의** | **0~3만원** | **제한적** | **높음** | **추천** |

**시작할 때 주의 사항:**
- 입문자 전용 커리큘럼 강의를 선택합니다 (기초 자세 → 개방 코드 → 스트로킹 → 바레 코드 순)
- 자가 촬영 또는 거울로 자세를 자주 비교합니다 (실시간 피드백 대체)
- F 바레 코드 슬럼프(2개월 전후)는 정상 — 강의를 끊지 않고 집중 반복
- 메트로놈을 처음부터 사용합니다 (무료 앱 활용)
- **F코드에서 막히면:** 단기 보충 레슨 1~2회 병행 가능 (대안: 학원)

- **2주 이상 미달 시** → 주 2회로 줄이고, 마일스톤을 2~3주 뒤로 조정
