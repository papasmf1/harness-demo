# 기타 목표 문서

## 핵심 목표
> 6개월 안에, 주 3회 1시간씩 연습하여 좋아하는 가요 10곡을 코드 반주로 처음부터 끝까지 혼자 연주한다.

---

## SMART 분석

| 항목 | 내용 |
|---|---|
| Specific | 좋아하는 가요 10곡을 선정하고, 각 곡을 코드 반주(스트로킹 포함) 형식으로 처음부터 끝까지 연주한다 |
| Measurable | 10곡 각각을 반주 없이 단독으로 연주하고, 중간에 멈추지 않고 완주하면 달성으로 판정한다 |
| Achievable | 주 3회 × 1시간 = 월 12시간, 6개월 누적 72시간. 코드 기반 반주 중심으로 학습하면 초보자도 간단한 곡부터 순차적으로 익힐 수 있다. 단, 10곡은 도전적인 수치이므로 아래 조정 제안 참고 |
| Relevant | 오랫동안 가져온 기타 취미에 대한 바람을 실현하고, 좋아하는 가요를 직접 연주하는 즐거움을 경험한다 |
| Time-bound | 2026년 5월 8일 시작 → 2026년 11월 8일(6개월 후)까지 완료 |

---

## 현재 수준

- 경험: 없음 (완전 초보자)
- 주당 가용 시간: 주 3회 × 1시간 (총 월 12시간)
- 예산 한도: 50만원

---

## 월간 마일스톤

| 시점 | 목표 |
|---|---|
| 1개월 | 기타 기초 자세·피킹·손가락 굳히기 완료. Am·Em·G·C·D 5개 기본 코드 전환 연습. 연습곡 1곡 완주 |
| 2개월 | 추가 코드(F 바레 코드 포함) 진입. 스트로킹 패턴 2~3가지 습득. 목표곡 중 쉬운 2곡 완주 |
| 3개월 | 목표곡 총 4곡 완주. 코드 전환 속도 안정화. 리듬감 훈련 (메트로놈 활용) |
| 4개월 | 목표곡 총 6곡 완주. 조금 어려운 곡(빠른 템포·복잡한 코드 진행) 진입 |
| 5개월 | 목표곡 총 8곡 완주. 부족한 곡 보완 연습. 중간 점검 및 연습 루틴 조정 |
| 6개월 | 목표곡 10곡 전 완주. 최종 자기 녹음·영상으로 달성 여부 확인 |

---

## 조정 제안

**솔직한 평가: "가요 10곡"은 초보자 6개월 기준으로 도전적입니다.**

- 6개월 72시간 학습 기간 내에 코드 기반 반주 10곡 완주는 **가능하지만 빡빡한 목표**입니다.
- 관건은 **F 바레 코드** 습득 시기입니다. F코드가 필요한 곡이 많은데, 초보자는 이 코드를 익히는 데만 2~4주가 걸립니다.
- 선정 곡 난이도가 낮을수록(예: 쉬운 3코드·4코드 곡 위주) 10곡 달성 확률이 높아집니다.

**권장 조정안 2가지:**

| 안 | 내용 | 장점 |
|---|---|---|
| A안 (유지) | 10곡, 단 곡 선정 시 난이도 낮은 곡 우선 배치 | 원래 목표 달성. 성취감 극대화 |
| B안 (현실적) | 6곡으로 목표 하향, 나머지 4곡은 "보너스 도전" 설정 | 중도 포기 위험 낮춤. 꾸준함 유지에 유리 |

- 예산 50만원은 기타 입문용 세트(기타+튜너+피크+케이스) 구매와 온라인 강의 수강에 충분합니다. 별도 오프라인 레슨 병행 시 비용 초과 가능성이 있으므로 장비 예산과 레슨 예산을 미리 분리하는 것을 권장합니다.
