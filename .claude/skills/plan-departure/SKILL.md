# 출발 시간 역산

## 목적

"언제 나가야 하지?"를 아침에 생각하지 않도록 출발 시간을 공식으로 계산합니다.

## 핵심 공식 (고정)

```
출발 시간 = 도착 목표 시간 - 이동 시간 - 여유 10분
기상 후 준비 가용 시간 = 출발 시간 - 기상 시간
```

이 공식은 변경하지 않습니다. 여유 10분은 항상 포함됩니다.

## 절차

### 1단계: 입력 확인

- 도착 목표 시간 — 필수 (01-alarm.md에서 읽거나 사용자 입력)
- 이동 시간 — 필수
- 기상 시간 — 01-alarm.md에서 읽음

### 2단계: 출발 시간 계산

공식 적용:
- 출발 시간 = 도착 목표 - 이동 시간 - 10분(여유)
- 준비 가용 시간 = 출발 시간 - 기상 시간

### 3단계: 분 단위 타임라인 작성

준비 가용 시간을 아래 비율로 배분합니다 (기본값):

| 구간 | 비율 | 내용 |
|---|---|---|
| 세면·씻기 | 40% | 샤워 or 세수·양치 |
| 옷 입기 | 10% | 미리 꺼내둔 옷 착용 |
| 아침 식사 | 35% | 03-breakfast.md 계획 실행 |
| 최종 점검 | 15% | 가방·소지품 최종 확인 |

### 4단계: 산출물 작성

`morning/artifacts/04-departure.md`에 저장합니다.
