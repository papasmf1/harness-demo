# 행사 역할 분담 매뉴얼

## 목적

행사 당일 "이건 누가 해요?"가 나오지 않도록, 모든 역할에 담당자와 대리인을 미리 배정합니다.

## 절차

1. `event/artifacts/01-rules.md`를 읽어 인원 구성과 행사 성격을 파악한다.
2. 행사에 필요한 역할 목록을 먼저 만든다.
3. 각 역할에 담당자·대리인·역할 설명을 채운다.
4. 실제 이름이 없으면 역할 이름으로만 표시한다.

## 기본 역할 목록 (참고)

행사 규모와 성격에 맞게 추가·제거합니다.

| 역할 | 설명 |
|---|---|
| 사회자 | 행사 흐름 진행, 안내 방송 |
| 음식 담당 | 음식 준비·배식·정리 |
| 게임·활동 진행 | 프로그램 운영, 참가자 안내 |
| 안전 담당 | 현장 안전 점검, 응급 상황 대응 |
| 기록 담당 | 사진·영상 촬영 |
| 정리 담당 | 행사 후 현장 정리 |

## 산출물 형식

```md
# [행사 이름] 역할 분담표

| 역할 | 담당자 | 대리인 | 역할 설명 |
|---|---|---|---|
| 사회자 | | | 행사 흐름 진행, 안내 방송 |
| 음식 담당 | | | 음식 준비·배식·정리 |
| 게임·활동 진행 | | | 프로그램 운영 |
| 안전 담당 | | | 현장 점검, 응급 대응 |
| 기록 담당 | | | 사진·영상 촬영 |
| 정리 담당 | | | 행사 후 현장 정리 |

## 역할 배정 시 참고 사항
- 안전 담당은 반드시 1명 이상 지정합니다.
- 사회자와 음식 담당은 겸직하지 않습니다.
- 담당자 이름은 주최자가 직접 채워야 합니다.
```

## 품질 기준

- 안전 담당 역할은 반드시 포함합니다.
- 20명 이하 행사는 5-7개 역할이 적당합니다.
- 한 사람이 너무 많은 역할을 맡지 않도록 안내합니다.
- 실제 이름 배정은 주최자 몫임을 명시합니다.
