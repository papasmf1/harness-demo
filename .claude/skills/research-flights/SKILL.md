# 항공권 리서치 매뉴얼

## 목적

항공권을 직접 찾아주는 것이 아니라, 사용자가 스스로 비교할 때 놓치지 말아야 할 기준을 정리해줍니다.

## 절차

1. 출발지·목적지·날짜·예산을 확인한다.
2. 직항/경유 옵션의 장단점을 정리한다.
3. 수하물 포함 여부를 반드시 확인 항목으로 표시한다.
4. 환불·변경 정책 확인 항목을 포함한다.
5. 비교 추천 플랫폼을 안내한다 (특정 URL 없이 플랫폼 이름만).

## 산출물 형식

```md
## 항공권 체크포인트

**기본 정보**
- 출발지 → 목적지:
- 출발일 / 귀국일:
- 예산 범위:

**비교 시 확인 항목**
- [ ] 직항 vs 경유 (경유 시 환승 대기 시간 확인)
- [ ] 수하물 포함 여부 (기내 수하물 kg 한도, 위탁 수하물 유료 여부)
- [ ] 환불·변경 조건 (무료 변경 가능 기간)
- [ ] 출발·도착 공항 (제2터미널 여부)
- [ ] 항공사 마일리지 적립 여부

**추천 비교 방법**
- 네이버 항공, 스카이스캐너, 구글 플라이트에서 동일 조건 비교
- 출발 2-3개월 전 예약이 일반적으로 유리

**⚠️ Handoff 메모 (다음 단계 참조용)**
- 확정 항공사:
- 수하물 규정:
- 여행 기간:
```

## 품질 기준

- 직접 예약 링크나 가격을 제시하지 않습니다.
- 수하물 규정은 반드시 포함합니다 (packing-agent가 참조합니다).
- Handoff 메모 칸은 항상 포함하되, 미확정 항목은 빈칸으로 남깁니다.
