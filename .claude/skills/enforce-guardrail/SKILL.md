# Guardrail 적용 작업 매뉴얼

## 금지 항목 목록

아래 항목은 금액·이유와 무관하게 즉시 차단합니다:

| 번호 | 금지 항목 | 감지 키워드 |
|---|---|---|
| G1 | 비상금 통장 임의 인출 | 비상금, 비상 통장, 긴급 자금 인출 |
| G2 | 적금·투자 계좌 중도 해지 | 적금 해지, 펀드 환매, 투자 인출 |
| G3 | 이번 달 예산 한도 자체 변경 | 예산 수정, 한도 올려줘, monthly-plan 변경 |

## 절차

1. 지출 요청 텍스트에서 금지 키워드 감지

2. 감지 시 → 즉시 BLOCK 판정, 이유 작성

3. 감지 안 됨 → check-budget-limit으로 넘김

## 차단 메시지 형식

```
🚫 차단: [G1/G2/G3] — [금지 항목명]
이유: 이 항목은 예산 규칙상 자동 차단됩니다.
대안: [해당 시 — 예: 큰 지출은 approval-agent를 통해 요청하세요]
```

## 품질 체크

- [ ] 금지 항목을 금액 조건 없이 차단
- [ ] 차단 이유와 대안 안내 포함
- [ ] expense-logger에 BLOCK 기록 전달
