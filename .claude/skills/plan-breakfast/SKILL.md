# 아침 식사 계획

## 목적

아침 준비 시간 중 식사에 드는 시간을 15분 이내로 줄입니다. 전날 미리 할 수 있는 것은 전날 합니다.

## 절차

### 1단계: 입력 확인

- 기상~출발 준비 시간 중 식사에 쓸 수 있는 시간 (없으면 15분으로 가정)
- 식이 제한 또는 선호 — 없으면 일반식으로 진행
- 냉장고 재료 여부 (00-audit.md에서 확인)

### 2단계: 메뉴 분류

가용 시간에 따라 메뉴를 분류합니다:

| 가용 시간 | 적합 메뉴 예시 |
|---|---|
| 5분 이내 | 시리얼+우유, 요거트+과일, 에너지바, 전날 준비 샌드위치 |
| 5~10분 | 토스트+계란, 남은 밥+김치, 컵라면 |
| 10~15분 | 오트밀, 간단한 볶음밥, 냉동 간편식 |

### 3단계: 전날 vs 당일 준비 분리

- **전날 저녁 준비**: 재료 꺼내두기, 샌드위치 미리 만들기, 과일 썰어두기 등
- **당일 아침 준비**: 가열, 완성, 섭취

### 4단계: 산출물 작성

`morning/artifacts/03-breakfast.md`에 저장합니다.

## 산출물 형식

```md
# 아침 식사 계획

> 식사 가용 시간: [  ]분 | 제한 사항: [없음 / 있으면 기록]

## 추천 메뉴

**메뉴**: [  ]
**총 준비+섭취 시간**: 약 [  ]분

## 전날 저녁 미리 할 것

- [ ] [항목 1]
- [ ] [항목 2]

## 당일 아침에 할 것

- [ ] [항목 1] — 약 [  ]분
- [ ] [항목 2] — 약 [  ]분

> 15분 안에 끝내려면 전날 준비 항목을 반드시 실행하세요.
```
