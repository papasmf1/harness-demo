# 행사 준비물 목록 작성 매뉴얼

## 목적

행사 당일 부족한 것이 없도록, 카테고리별로 준비물을 정리합니다. 각 항목에 수량과 담당자 칸을 포함해서 역할 분담과 연결되도록 합니다.

## 절차

1. `event/artifacts/01-rules.md`를 읽어 인원 수, 테마, 장소 유형(실내/야외)을 파악한다.
2. 아래 4개 카테고리별로 목록을 채운다.
3. 각 항목에 수량과 담당자 칸을 붙인다.

## 4개 카테고리

| 카테고리 | 포함할 것 |
|---|---|
| 음식·음료 | 식재료, 완성 음식, 음료, 아이스박스, 서빙 도구 |
| 도구·장비 | 테이블, 의자, 텐트, 전기 연결, 쓰레기봉투 |
| 안전·구급 | 구급함, 소화기 위치 확인, 응급 연락처 카드 |
| 기타 | 장식, 게임 도구, 인쇄물(명찰, 프로그램표), 카메라 |

## 산출물 형식

```md
# [행사 이름] 준비물 목록

## 음식·음료
| 항목 | 수량 | 담당 |
|---|---|---|
| | | |

## 도구·장비
| 항목 | 수량 | 담당 |
|---|---|---|
| | | |

## 안전·구급
| 항목 | 수량 | 담당 |
|---|---|---|
| | | |

## 기타
| 항목 | 수량 | 담당 |
|---|---|---|
| | | |

## 구매 필요 항목 (없는 것)
- 
```

## 품질 기준

- 4개 카테고리는 모두 포함합니다. 해당 없는 항목은 "해당 없음"으로 표시합니다.
- 수량은 인원 수를 기준으로 계산합니다. (예: 20명 → 음료 30개)
- 안전·구급 카테고리는 행사 규모와 무관하게 항상 포함합니다.
- 담당 칸은 역할 분담 담당이 채울 수 있도록 비워 둡니다.
