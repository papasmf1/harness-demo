# 점검 일정 작성 매뉴얼

## 목적

여행 준비가 마감 직전에 몰리지 않도록, 각 준비 항목을 시점별로 분산해서 일정으로 만듭니다.

## 기본 원칙

- 예약이 필요한 것(항공권, 숙소)은 가장 먼저 합니다.
- 가입·신청이 필요한 것(보험, 트래블카드)은 1-2주 전에 합니다.
- 짐과 집 정리는 출발 3-7일 전에 합니다.
- 최종 확인은 출발 전날과 당일에 합니다.

## 절차

1. 출발일을 확인한다.
2. D-30, D-14, D-7, D-3, D-1, D-Day 시점별 항목을 배분한다.
3. 각 시점에 담당 팀원(어떤 체크리스트)을 연결한다.

## 산출물 형식

```md
## D-Day 점검 일정

**출발일:** [YYYY-MM-DD]
**귀국일:** [YYYY-MM-DD]

### D-30 이전 (한 달 전)
- [ ] 항공권 예약 완료 → `01-logistics.md` 참조
- [ ] 숙소 예약 완료 → `01-logistics.md` 참조
- [ ] 여행자 보험 가입 → `02-finance.md` 참조

### D-14 (2주 전)
- [ ] 환전 또는 트래블카드 준비 → `02-finance.md` 참조
- [ ] 해외 카드 사용 한도 확인
- [ ] 비자 필요 여부 최종 확인 및 신청

### D-7 (1주 전)
- [ ] 짐 목록 작성 및 1차 정리 → `03-packing.md` 참조
- [ ] 이메일 자동 응답 설정
- [ ] 긴급 업무 위임 완료

### D-3 (3일 전)
- [ ] 짐 대부분 챙기기 (필수품 제외)
- [ ] 반려식물·동물 부탁 완료
- [ ] 냉장고 정리 시작

### D-1 (전날)
- [ ] 짐 최종 점검 → `03-packing.md` 체크리스트
- [ ] 여권·항공권·보험 서류 확인
- [ ] 공항 이동 방법 및 시간 확인
- [ ] 가족·지인에게 일정 공유

### D-Day (출발 당일)
- [ ] Clean state 최종 확인 → `04-home.md` 참조
- [ ] 가스·창문·전자기기 플러그 확인
- [ ] 여권·지갑·스마트폰 최종 확인
- [ ] 공항 도착 (국제선 기준 출발 3시간 전)
```

## 품질 기준

- D-30, D-14, D-7, D-3, D-1, D-Day 6개 시점은 반드시 포함합니다.
- 각 항목에 참조 파일을 연결합니다.
- 출발일이 30일 미만으로 임박한 경우, 해당 시점을 생략하고 남은 항목을 앞당깁니다.
