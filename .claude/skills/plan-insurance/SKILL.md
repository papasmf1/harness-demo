# 여행자 보험 준비 매뉴얼

## 목적

보험을 대신 가입하지 않고, 사용자가 상품을 비교할 때 놓치면 안 되는 보장 항목을 체크리스트로 정리합니다.

## 필수 3대 보장 항목

어떤 여행자 보험이든 아래 3가지는 반드시 포함되어야 합니다.

1. **해외 의료비** — 현지 병원 치료비 실손 보장 (최소 1억원 이상 권장)
2. **항공 지연·취소** — 일정 시간 이상 지연 시 보상
3. **수하물 분실·파손** — 위탁 수하물 분실·파손 보장

## 절차

1. 여행 기간과 목적지를 확인한다.
2. 목적지 국가의 의료비 수준을 반영한다 (미국·유럽은 의료비가 특히 높음).
3. 필수 3대 항목 보장 한도를 확인 항목으로 포함한다.
4. 신용카드 부가 보험과 중복 여부를 확인하도록 안내한다.

## 산출물 형식

```md
## 여행자 보험 체크리스트

**필수 보장 항목**
- [ ] 해외 의료비 실손 (보장 한도 확인 — 유럽/미국은 최소 5천만원 권장)
- [ ] 항공 지연·취소 보상 (기준 시간: 보통 3-6시간 이상)
- [ ] 수하물 분실·파손 보상 (한도 및 면책 조건 확인)

**추가 확인 항목**
- [ ] 액티비티 중 상해 보장 여부 (스포츠·등산 포함 여부)
- [ ] 코로나 등 감염병 관련 의료비 포함 여부
- [ ] 긴급 의료 후송 보장 여부

**중복 확인**
- [ ] 보유 신용카드 해외여행 보험 혜택 범위 먼저 확인
- [ ] 중복 보장 항목은 제외하고 부족한 부분만 추가 가입

**가입 시기**
- 출발 최소 1-2주 전 가입 권장
- 출발 당일 가입 가능한 상품도 있으나 일부 보장 제외될 수 있음
```

## 품질 기준

- 특정 보험사를 추천하지 않습니다.
- 필수 3대 항목은 반드시 포함합니다.
- 목적지가 의료비 고비용 국가(미국, 서유럽)면 보장 한도 권장 금액을 높게 안내합니다.
