# 장소·음식 기획 작업 매뉴얼

## 절차

1. **입력 읽기**
   - `party/artifacts/01-ideas.md` (채택된 아이디어 확인)
   - `party/artifacts/02-evaluation.md` (WARN 항목 확인)
   - 부모 조건 (날짜, 지역, 알레르기, 선호 음식, 예산 잔액)

2. **장소 선정**
   - 1순위: 예산 안에서 테마에 맞는 최선의 장소
   - 2순위: 더 저렴한 대안 (집, 공원, 무료 공간 등)
   - 각 장소에 수용 인원, 예상 비용, 예약 방법 명시
   - 예약 필요 여부와 D-14 이전 예약 권장 표시

3. **음식 메뉴 구성**
   - 케이크: 테마에 맞는 디자인 + 인원수 기준 크기
   - 핑거푸드 3~5가지: 아이가 먹기 쉬운 한 입 크기
   - 음료: 무알코올, 과일주스 위주
   - 알레르기 유발 식재료 → ⚠️ 표시 또는 대체재 제안

4. **준비 일정 작성**
   - D-14: 장소 예약 확인
   - D-7: 케이크 주문 (맞춤 케이크는 D-14 권장)
   - D-3: 장보기·식재료 구매
   - D-1: 세팅 준비, 장식 구매

5. **예산 소계 계산**
   - 장소 + 케이크 + 음식·음료 합계
   - 전체 예산 대비 잔액 표시

6. **파일 저장**
   - `party/artifacts/03-venue-food.md`에 저장

- [ ] 준비 일정 D-14~D-Day 포함
