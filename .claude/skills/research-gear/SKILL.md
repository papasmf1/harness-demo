# 장비 조사 매뉴얼

## 목적

처음 취미를 시작할 때 무엇을 사야 할지, 얼마가 드는지 한눈에 파악할 수 있도록 장비 목록을 만듭니다. 초보자 첫 3개월 기준으로 필요한 것만 포함합니다.

## 3가지 장비 분류

| 분류 | 기준 |
|---|---|
| 필수 | 없으면 시작 자체가 불가능한 것 |
| 권장 | 없어도 되지만 있으면 크게 도움되는 것 |
| 선택 | 익숙해진 뒤에 사도 되는 것 |

## 절차

1. `01-goal.md`에서 취미 종류와 예산 한도를 파악한다.
2. `02-method.md`에서 학습 방식을 확인한다 (학원이면 악기 대여 가능 여부 등).
3. 필수 → 권장 → 선택 순서로 목록을 작성한다.
4. 각 항목에 가격 범위(최소~최대)를 붙인다.
5. 필수 + 권장 합계를 총 예상 비용으로 계산한다.

## 산출물 형식

```md
# [취미 이름] 장비 목록

## 필수 장비
| 항목 | 가격 범위 | 비고 |
|---|---|---|
| | | |

## 권장 장비
| 항목 | 가격 범위 | 비고 |
|---|---|---|
| | | |

## 선택 장비 (나중에 구매 가능)
| 항목 | 가격 범위 | 비고 |
|---|---|---|
| | | |

## 비용 요약
| 구분 | 금액 |
|---|---|
| 필수 장비 합계 | 원 |
| 권장 장비 합계 | 원 |
| **총 예상 비용 (필수+권장)** | **원** |
| 사용자 예산 한도 | 원 |

## 예산 점검 담당에게
총 예상 비용: [금액]원 / 예산 한도: [금액]원
```

## 품질 기준

- 필수 항목은 5개를 넘지 않게 합니다. 진짜 필수만 포함합니다.
- 가격 범위는 최소~최대로 씁니다. (예: 5만원~15만원)
- 특정 브랜드나 쇼핑몰 링크는 포함하지 않습니다.
- 학원 방식이면 "악기 대여 가능 여부 확인 권장" 메모를 추가합니다.
