# 숙소 확인 매뉴얼

## 목적

숙소를 대신 예약하지 않고, 사용자가 예약할 때 반드시 확인해야 할 기준을 체크리스트로 정리합니다.

## 절차

1. 목적지와 여행 기간을 확인한다.
2. 숙소 유형별 (호텔/에어비앤비/호스텔) 확인 항목을 나눈다.
3. 위치·취소정책·조식 포함 여부를 필수 항목으로 표시한다.
4. 장기 여행(1주 이상)에 특화된 항목을 추가한다 (세탁, 주방, 연박 할인).

## 산출물 형식

```md
## 숙소 체크포인트

**공통 확인 항목**
- [ ] 위치 (대중교통 접근성, 주요 관광지 거리)
- [ ] 취소 정책 (무료 취소 기한)
- [ ] 조식 포함 여부 및 비용
- [ ] 체크인/체크아웃 시간
- [ ] Wi-Fi 무료 제공 여부
- [ ] 리뷰 최근 6개월 기준 평점 확인

**장기 여행(1주 이상) 추가 확인**
- [ ] 세탁기 또는 코인세탁 근처 여부
- [ ] 주방 또는 냉장고 사용 가능 여부
- [ ] 연박 할인 협의 가능 여부
- [ ] 귀중품 보관함(세이프티박스) 여부

**추천 비교 방법**
- 부킹닷컴, 호텔스컴바인, 에어비앤비에서 동일 기간 비교
- 숙소 분산 vs. 거점 1곳 선택 여부 먼저 결정
```

## 품질 기준

- 특정 숙소를 추천하지 않습니다. 선택 기준만 정리합니다.
- 장기 여행(2주)이면 세탁·주방 항목을 필수로 포함합니다.
- 취소정책 확인 항목은 반드시 포함합니다.
