# 아이디어 생성 작업 매뉴얼

## 절차

1. **입력 확인**
   - 아이 나이 → 없으면 묻기
   - 예산 상한 → 없으면 묻기
   - 테마 (없으면 나이에 맞는 인기 테마 3가지 제안 후 선택)
   - 예상 인원 (없으면 "10명 이하"로 가정, 가정 사실 명시)

2. **아이디어 3가지 작성**
   - 각 아이디어는 테마·예상 비용·주요 활동·음식 방향을 포함
   - 예산 범위 내에서 비용 낮은 순→높은 순으로 배열
   - 나이별 안전 기준 적용 (3세 이하: 소품 크기 주의, 7세 이하: 규칙 단순화)

3. **활동 아이디어 추가**
   - 최소 3가지 (실내·실외 각 1가지 이상)
   - 나이에 맞는 게임·체험 포함

4. **음식 아이디어 추가**
   - 케이크 종류 제안
   - 핑거푸드 3~5가지
   - 알레르기 유발 재료가 있으면 ⚠️ 표시

5. **파일 저장**
   - `party/artifacts/01-ideas.md`에 저장

## 품질 체크

- [ ] 아이디어 3가지 모두 예산 범위 이내
- [ ] 각 아이디어에 예상 비용 명시
- [ ] 나이 부적합 활동 없음
- [ ] 알레르기 식재료 표시 완료
