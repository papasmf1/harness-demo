# 행사 기본 규칙 작성 매뉴얼

## 목적

행사 시작 전에 모든 참가자가 알아야 할 규칙을 한 문서에 모읍니다. 이 문서는 준비물·역할·일정 담당이 기준으로 삼는 첫 번째 산출물입니다.

## 절차

1. 행사 정보(종류, 날짜, 장소, 인원, 테마)를 확인한다.
2. 아래 6개 항목을 순서대로 채운다.
3. 모르는 항목은 "미정 — 주최자 확인 필요"로 표시한다.

## 6개 필수 항목

| 항목 | 설명 |
|---|---|
| 행사 개요 | 행사 이름, 날짜, 장소, 예상 인원 |
| 참가 조건 | 나이 제한, 초대 방식, 참가비 유무 |
| 시간 규칙 | 시작·종료 시간, 입장 가능 시간 |
| 날씨·취소 방침 | 우천 시 대응(취소·연기·실내 이동), 결정 공지 시점 |
| 금지 사항 | 반려동물, 흡연, 음주, 위험 물품 등 |
| 연락처 | 주최자 이름 + 연락처 (비상시 기준) |

## 산출물 형식

```md
# [행사 이름] 기본 규칙

## 행사 개요
- 날짜: 
- 장소: 
- 예상 인원: 
- 테마: 

## 참가 조건
- 

## 시간 규칙
- 입장 가능: 
- 공식 시작: 
- 종료 예정: 

## 날씨·취소 방침
- 우천 시: 
- 취소 결정 공지: 

## 금지 사항
- 

## 주최자 연락처
- 이름: 
- 연락처: 
```

## 품질 기준

- 6개 항목은 모두 포함합니다. 정보가 없으면 "미정"으로 표시합니다.
- 규칙은 짧고 명확하게 씁니다. 설명이 필요한 항목에만 한 줄 이유를 추가합니다.
- 완성된 문서는 참가자에게 그대로 공유할 수 있는 수준이어야 합니다.
