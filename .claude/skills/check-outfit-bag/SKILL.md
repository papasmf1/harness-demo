# 옷·가방 점검 체크리스트

## 목적

아침에 "뭐 입지?"로 낭비하는 시간을 없앱니다. 전날 저녁 5분이 아침 10분을 절약합니다.

## 절차

### 1단계: 입력 확인

- 목적 (출근/등교/외출) — 없으면 출근으로 가정
- 내일 날씨 (00-audit.md에서 읽거나 사용자 입력)
- 특이 일정 (발표, 미팅, 체육 등) — 없으면 일반으로 진행

### 2단계: 옷 항목 결정

- 상의 → 날씨·일정에 맞게
- 하의
- 겉옷 (기온 15°C 이하 또는 비 예보 시 필수)
- 신발
- 우산 (비 예보 시 추가)

### 3단계: 가방 소지품 확인

필수 소지품 (항상 포함):
- 지갑 (현금·카드)
- 교통카드
- 열쇠 (집 열쇠·사무실 카드 등)
- 스마트폰

목적별 추가 소지품:
- 출근: 노트북·충전기·이어폰
- 등교: 교재·과제물·필기도구
- 기타: 사용자 입력

### 4단계: 산출물 작성

`morning/artifacts/02-outfit.md`에 저장합니다.

## 산출물 형식

```md
# 옷·가방 점검 체크리스트

> 날짜: [내일 날짜] | 목적: [출근/등교] | 날씨: [  ]°C, 비: [예/아니오]

## 옷

- [ ] 상의: [  ]
- [ ] 하의: [  ]
- [ ] 겉옷: [  ] (기온 [  ]°C 기준)
- [ ] 신발: [  ]
- [ ] 우산: [필요 / 불필요]

## 가방 소지품

**필수**
- [ ] 지갑
- [ ] 교통카드
- [ ] 열쇠
- [ ] 스마트폰

**목적별 추가**
- [ ] [항목 1]
- [ ] [항목 2]

> 전날 저녁 이 목록을 모두 체크한 뒤 가방에 넣어두세요.
```
