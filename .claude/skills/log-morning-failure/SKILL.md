# 아침 루틴 실패 원인 기록

## 목적

실패를 기록하여 패턴을 찾습니다. 같은 이유로 두 번 이상 늦으면 루틴을 고쳐야 한다는 신호입니다.

## 5개 실패 카테고리 (고정)

| 카테고리 | 해당 사례 |
|---|---|
| A. 기상 실패 | 늦잠, 알람 못 들음, 스누즈 반복 |
| B. 준비 지연 | 옷 못 찾음, 가방 못 챙김, 식사 오래 걸림 |
| C. 이동 지연 | 버스·지하철 놓침, 출발 자체가 늦음 |
| D. 전날 미준비 | Environment Audit 미실행, 짐 미리 안 챙김 |
| E. 외부 요인 | 교통 사고, 날씨, 컨디션 불량 등 통제 불가 |

이 카테고리는 변경하지 않습니다.

## 절차

### 1단계: 실패 메모 분석

사용자가 입력한 오늘 아침 실패 메모를 읽습니다.

### 2단계: 카테고리 분류

메모를 A~E 카테고리에 매핑합니다. 복수 카테고리 허용.

### 3단계: progress.md 확인

- `morning/progress.md`가 없으면 새로 만듭니다.
- 있으면 기존 내용을 읽고 맨 아래에 추가합니다.

### 4단계: 누적 통계 업데이트

파일 맨 위의 통계 표를 현재 기록 기준으로 갱신합니다.

### 5단계: 산출물 작성

`morning/progress.md`에 추가합니다.

## 산출물 형식 (progress.md 누적 구조)

```md
# 아침 루틴 실패 기록

## 누적 통계

| 카테고리 | 횟수 |
|---|---|
| A. 기상 실패 | [  ] |
| B. 준비 지연 | [  ] |
| C. 이동 지연 | [  ] |
| D. 전날 미준비 | [  ] |
| E. 외부 요인 | [  ] |

> 2회 이상 카테고리는 다음 설정 모드 실행 시 Environment Audit 상단에 반영됩니다.

---

## 기록

### [날짜]

- **실패 메모**: [사용자 입력 원문]
- **카테고리**: [A / B / C / D / E]
- **분석**: [한 문장 — 왜 이 카테고리인지]
- **다음 번 시도할 것**: [한 가지 구체적 행동]

---
```

## 두께 (Thickness)

이 스킬은 **두꺼운(Thick) 스킬**입니다. 5개 카테고리(A~E)와 누적 통계 표 형식은 고정입니다. 분류 기준이 일관되어야 통계가 의미 있습니다.
