# 짐 목록 작성 매뉴얼

## 목적

2주 해외여행에 필요한 짐을 빠짐없이, 그리고 수하물 규정 안에서 정리합니다.

## 절차

1. 항공사 수하물 규정을 확인한다 (기내 kg·크기, 위탁 kg).
2. 기내 반입 불가 항목을 먼저 확인한다 (액체류 100ml 이상 등).
3. 카테고리별로 목록을 작성한다.
4. 각 항목을 기내용 / 위탁용으로 구분한다.
5. 목적지 계절과 여행 성격을 반영해 의류 수량을 조정한다.

## 카테고리

- **서류·결제**: 여권, 비자, 항공권 확인서, 보험 증서, 신용카드, 현금
- **의류**: 목적지 날씨 기준 (2주 기준 상의 7-8벌, 하의 3-4벌 권장)
- **세면·위생**: 치약·칫솔, 샴푸·바디워시(100ml 이하 기내용), 선크림
- **전자기기**: 스마트폰, 노트북(선택), 충전기, 여행용 어댑터, 보조배터리(기내 필수)
- **의약품**: 소화제, 감기약, 지사제, 밴드, 상비약
- **비상용품**: 자물쇠, 목베개, 안대, 이어플러그

## 산출물 형식

```md
## 짐 체크리스트

**수하물 규정 요약**
- 기내 수하물: [kg] / [크기]
- 위탁 수하물: [kg]

### 🛂 기내 수하물 (반드시 기내 반입)
- [ ] 여권
- [ ] 항공권 확인서 (출력 또는 앱)
- [ ] 보조배터리 (리튬배터리는 기내만 가능)
- [ ] 지갑 (현금 + 카드)
- [ ] 세면용품 100ml 이하 지퍼백 포장

### 🧳 위탁 수하물
**서류·결제**
- [ ] 여행자 보험 증서 사본
- [ ] 비상 현금 (숙소 보관함 보관 예정)

**의류** (2주 기준)
- [ ] 상의 7-8벌
- [ ] 하의 3-4벌
- [ ] 속옷 7-8벌
- [ ] 잠옷 1-2벌
- [ ] 외투 1벌 (계절 따라)
- [ ] 편한 신발 1켤레 + 상황별 신발

**세면·위생**
- [ ] 샴푸·바디워시 (현지 구매 또는 위탁)
- [ ] 선크림
- [ ] 화장품

**전자기기**
- [ ] 충전기 세트
- [ ] 여행용 어댑터
- [ ] 이어폰

**의약품**
- [ ] 소화제, 감기약, 지사제, 진통제
- [ ] 밴드, 소독약

**⚠️ 확인 필요**
- [ ] 액체류 100ml 이하 규정 재확인
- [ ] 목적지 반입 금지 품목 확인
```

## 품질 기준

- 기내·위탁 구분을 반드시 표시합니다.
- 보조배터리는 항상 기내 수하물로 안내합니다.
- 2주 기준 의류 수량 가이드를 포함합니다.
- 수하물 규정이 미확정이면 IATA 일반 기준(기내 7kg, 위탁 23kg)을 기본으로 사용하고 확인 필요 표시를 남깁니다.
