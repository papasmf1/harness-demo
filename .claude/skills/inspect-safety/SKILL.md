# 행사 안전 점검 매뉴얼

## 목적

행사 당일 사고를 예방하고, 만약의 상황에 빠르게 대응할 수 있도록 안전 체크리스트를 만듭니다.

## 절차

1. `event/plan.md`를 읽어 장소, 인원, 활동 내용을 파악한다.
2. 장소 유형(실내/야외)에 따라 위험 요소를 선별한다.
3. 아래 3개 항목을 순서대로 작성한다.
4. 점검 시점을 "전날"과 "당일 아침" 두 번으로 나눈다.

## 3개 필수 항목

| 항목 | 내용 |
|---|---|
| 현장 위험 요소 | 장소·활동별 위험 요인과 예방 조치 |
| 구급용품 | 비치해야 할 용품 목록 |
| 비상 연락처 | 소방서·구급대·병원·주최자 |

## 장소별 주요 위험 요소 참고

**야외 행사:**
- 직사광선·열사병 (물·그늘 제공)
- 미끄러운 바닥·잔디 (안전선 표시)
- 화기 사용 (소화기 비치, 안전 거리 확보)
- 어린이 이탈 (관리 구역 지정)

**실내 행사:**
- 비상구 위치 확인
- 과도한 인원 밀집
- 전기 연결·열기구

## 산출물 형식

```md
# [행사 이름] 안전 점검 체크리스트

## 전날 점검
- [ ] 장소 답사 및 위험 요소 확인
- [ ] 구급용품 준비 완료
- [ ] 비상 연락처 카드 인쇄 및 배포 (안전 담당에게)
- [ ] 소화기 위치 확인

## 당일 아침 점검
- [ ] 현장 위험 요소 재확인
- [ ] 구급함 위치 안전 담당에게 공유
- [ ] 비상 연락처 카드 현장 게시

## 현장 위험 요소 및 예방 조치
| 위험 요소 | 예방 조치 |
|---|---|
| | |

## 구급용품 목록
| 용품 | 수량 | 비고 |
|---|---|---|
| 반창고 (대·소) | 각 5개 | |
| 소독약 | 1병 | |
| 거즈 붕대 | 3개 | |
| 냉찜질팩 | 3개 | |
| 진통제 | 1통 | 성인용 |

## 비상 연락처
| 기관 | 번호 |

| 행사 안전 담당 | (주최자 확인 필요) |
| 행사 주최자 | (주최자 확인 필요) |
```

## 품질 기준

- 전날·당일 아침 두 번의 점검 시점을 반드시 포함합니다.
- 구급용품 목록은 행사 규모와 무관하게 항상 포함합니다.
- 실제 연락처 번호는 지어내지 않습니다. 담당자가 채울 칸으로 남깁니다.
- 어린이 참가자가 있으면 어린이 안전 항목을 추가합니다.
