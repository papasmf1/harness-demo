# 행사 일정 타임라인 작성 매뉴얼

## 목적

행사 당일 흐름이 끊기지 않도록, 준비부터 마무리까지 시간대별 활동을 미리 정리합니다.

## 절차

1. `event/artifacts/01-rules.md`를 읽어 시작 시간, 종료 시간, 장소, 행사 성격을 파악한다.
2. 아래 4개 구간으로 나눈다.
3. 각 시간대에 활동과 담당 역할을 붙인다.

## 4개 구간

| 구간 | 내용 |
|---|---|
| 셋업 | 공식 시작 1-2시간 전, 장소 준비·설치 |
| 오프닝 | 참가자 입장, 인사, 행사 소개 |
| 본 행사 | 주요 활동, 식사, 프로그램 |
| 마무리 | 인사, 기념 촬영, 현장 정리 |

## 산출물 형식

```md
# [행사 이름] 당일 타임라인

## 셋업 (행사 시작 전)
| 시간 | 활동 | 담당 역할 |
|---|---|---|
| 00:00 | 장소 도착, 장비 설치 | 정리 담당 |
| 00:30 | 음식 준비 | 음식 담당 |

## 오프닝
| 시간 | 활동 | 담당 역할 |
|---|---|---|
| 00:00 | 참가자 입장·등록 | 사회자 |
| 00:15 | 인사 및 행사 소개 | 사회자 |

## 본 행사
| 시간 | 활동 | 담당 역할 |
|---|---|---|
| 00:00 | | |

## 마무리
| 시간 | 활동 | 담당 역할 |
|---|---|---|
| 00:00 | 폐회 인사 | 사회자 |
| 00:15 | 기념 촬영 | 기록 담당 |
| 00:30 | 현장 정리 | 정리 담당 |

## 비고
- 예상 시간이 포함된 항목은 실제 진행에 따라 조정할 수 있습니다.
- 비상 상황 발생 시 안전 담당이 사회자에게 즉시 알립니다.
```

## 품질 기준

- 시작 시간이 없으면 타임라인을 작성하지 않고 오케스트레이터에게 요청합니다.
- 셋업·오프닝·본 행사·마무리 4구간은 반드시 포함합니다.
- 각 항목의 담당 역할은 역할 분담표의 역할 이름과 일치시킵니다.
- 예상 소요 시간이 불확실한 항목은 "(예상)"이라고 표시합니다.
