# 연습 루틴 작성 매뉴얼

## 목적

꾸준히 실천할 수 있는 연습 루틴을 만듭니다. 너무 빡빡하면 며칠 못 가고 포기합니다. 현실적인 범위에서 습관으로 굳힐 수 있는 수준으로 작성합니다.

## 루틴 설계 원칙

- 하루 연습 시간: 초보자는 30분~1시간이 적당합니다.
- 주당 연습 횟수: 최소 3회를 권장합니다. 매일 하는 것보다 꾸준히 3회가 낫습니다.
- 구조: 워밍업(10%) → 핵심 연습(70%) → 마무리(20%)

## 절차

1. `01-goal.md`에서 기간, 마일스톤, 주당 가용 시간을 파악한다.
2. `02-method.md`에서 학습 방식(학원 레슨 요일 등)을 확인한다.
3. 주간 루틴과 월간 마일스톤을 작성한다.

## 산출물 형식

```md
# [취미 이름] 연습 루틴

## 주간 연습 계획
| 요일 | 연습 시간 | 내용 |
|---|---|---|
| 월 | | |
| 화 | | |
| 수 | | |
| 목 | | |
| 금 | | |
| 토 | | |
| 일 | | |

## 하루 연습 구조
| 구간 | 시간 | 내용 |
|---|---|---|
| 워밍업 | 분 | |
| 핵심 연습 | 분 | |
| 마무리 | 분 | |

## 월간 마일스톤
| 월 | 목표 | 확인 방법 |
|---|---|---|
| 1개월 | | |
| 2개월 | | |
| 3개월 | | |
| 6개월 | | |

## 루틴 조정 기준
- 2주 이상 연속 미달 시 → 연습 시간 또는 횟수 줄이기
- 마일스톤 조기 달성 시 → 다음 마일스톤 앞당기기
```

## 품질 기준

- 하루 연습 시간이 2시간을 넘지 않도록 합니다.
- 월간 마일스톤은 목표 문서의 마일스톤과 일치시킵니다.
- 학원 레슨이 있으면 레슨 다음 날을 복습일로 배치합니다.
- "조정 기준"은 반드시 포함합니다. 루틴은 고정이 아니라 조정하는 것입니다.
