# 월말 점검 작업 매뉴얼

## 절차

1. **입력 읽기**
   - `budget/expense-log.md` 전체 (해당 월 행만 필터)
   - `budget/monthly-plan.md` (카테고리별 한도)

2. **집계**
   - 카테고리별 PASS + APPROVED 금액 합산 (실제 지출)
   - BLOCK + REJECTED 건수 및 금액 집계 (차단 현황)
   - 전체 예산 대비 실제 지출 비율

3. **분석**
   - 초과 카테고리: 실제 지출 > 한도
   - 절약 카테고리: 실제 지출 < 한도 × 70%
   - 차단 비율이 높은 카테고리 → "지출 압박 주의" 표시

4. **다음 달 제안**
   - 초과 카테고리 → 한도 상향 또는 지출 절제 권고
   - 절약 카테고리 → 한도 유지 또는 여유분 재분배 제안
   - 변경 이유를 함께 작성

5. **보고서 저장**
   - `budget/monthly-report.md` (덮어쓰기, 월별로 새로 생성)

## 품질 체크

- [ ] PASS + APPROVED만 실제 지출로 계산
- [ ] BLOCK + REJECTED 건수를 별도 집계
- [ ] 다음 달 제안이 현재 데이터 기반 (임의 추측 금지)
- [ ] expense-log.md 수정 없음 (읽기만)
