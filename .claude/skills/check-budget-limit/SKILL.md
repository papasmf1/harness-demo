# 한도 확인 작업 매뉴얼

## 절차

1. **monthly-plan.md 읽기** — 해당 카테고리의 이번 달 한도 확인

2. **expense-log.md 읽기** — 해당 카테고리의 이번 달 PASS + APPROVED 건 합산

3. **계산**
   ```
   누적 지출 + 요청 금액 ≤ 카테고리 한도 → PASS
   누적 지출 + 요청 금액 > 카테고리 한도 → BLOCK
   ```

4. **카테고리 불일치** — 요청 카테고리가 monthly-plan.md에 없으면 "기타" 카테고리 적용. "기타"도 없으면 오케스트레이터에 카테고리 확인 요청.

5. **결과 반환** — 판정 + 잔액 + 사유

## 품질 체크

- [ ] 해당 월 PASS + APPROVED 건만 누적에 포함 (BLOCK, REJECTED 제외)
- [ ] 계산 근거(누적·한도·잔액) 결과에 명시
- [ ] 카테고리 불명확 시 임의 처리하지 않고 확인 요청
