# 초대 명단 검토 작업 매뉴얼

## 절차

1. **입력 받기**
   - 부모가 제공한 명단 (이름, 관계, 연락처)
   - `party/artifacts/03-venue-food.md`에서 장소 수용 인원 확인
   - 알레르기·식이 제한 정보

2. **명단 정리**
   - 표 형식으로 정리: 이름, 관계, 연락처, 알레르기·특이사항, 초대장 발송 여부
   - 연락처 없는 항목 → ⚠️ 표시
   - 알레르기 정보 없는 항목 → 확인 필요 표시

3. **수용 인원 점검**
   - 총 초대 인원 vs 장소 수용 가능 인원 비교
   - 초과 시 → 부모에게 확인 요청 (임의로 삭제 금지)

4. **초대장 발송 일정 확인**
   - 파티 D-14 이전 발송 권장
   - 발송 방법 제안 (카카오톡, 문자, 손편지)

5. **점검 결과 요약**
   - 4가지 체크리스트 항목 상태 표시
   - 특이사항 섹션에 알레르기·VIP 등 기록

6. **파일 저장**
   - `party/artifacts/04-guest-list.md`에 저장
