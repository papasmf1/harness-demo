# 질문 생성 매뉴얼

## 목적

책을 다 읽고 나서도 계속 생각하게 만드는 질문을 만듭니다. 좋은 질문은 답보다 더 오래 남습니다.

## 절차

1. 요약문에서 독자가 가장 큰 영향을 받았을 것 같은 지점을 찾는다.
2. "왜", "만약", "나라면" 형태의 질문을 우선으로 만든다.
3. 책의 주장에 반론이 될 수 있는 질문도 하나 포함한다.
4. 예/아니오로 끝날 수 있는 질문은 열린 질문으로 바꾼다.

## 질문 유형 가이드

| 유형 | 예시 |
|---|---|
| 이유 탐구 | "저자가 X를 강조한 이유는 무엇일까?" |
| 가정 도전 | "만약 이 방법이 내 상황에서는 안 된다면?" |
| 자기 적용 | "나는 이 원칙을 어느 부분에서 가장 어겨왔는가?" |
| 반론 | "이 주장의 약점이나 반례는 무엇인가?" |
| 확장 | "이 책의 논리를 다른 분야에 적용하면 어떻게 될까?" |

## 산출물 형식

```md
## 내가 가진 질문

1. (질문)
2. (질문)
3. (질문)
4. (질문 — 선택)
5. (질문 — 선택)
```

## 품질 기준

- 3개 이상, 5개 이하를 만듭니다.
- 모든 질문은 열린 질문이어야 합니다.
- 요약에 없는 내용으로 질문을 만들지 않습니다.

## 멈추고 질문할 조건

- 요약이 한 문단 미만으로 너무 짧을 때 → 독서 분석가 결과 파일이 완성됐는지 확인
