# 인용 선별 매뉴얼

## 목적

책에서 다시 꺼내 볼 만한 문장을 3-5개 골라, 나중에 글을 쓰거나 생각할 때 참고할 수 있게 정리합니다.

## 절차

1. 사용자 메모에서 직접 언급한 문장이 있으면 최우선으로 포함한다.
2. 감정적으로 강하게 남는 문장을 고른다 (공감, 놀라움, 반성 등).
3. 논리적으로 핵심인 문장을 고른다 (저자의 주장을 가장 잘 담은 것).
4. 페이지 정보가 있으면 포함하고, 없으면 "(위치 미상)"으로 표기한다.

## 산출물 형식

```md
## 인상적인 인용

1. "(인용 문장)" — p.XX
   *왜 골랐나: 한 줄 이유*

2. "(인용 문장)" — p.XX
   *왜 골랐나: 한 줄 이유*
```

## 품질 기준

- 5개를 초과하지 않습니다. 적을수록 더 기억에 남습니다.
- 인용 이유를 반드시 한 줄 씁니다. 이유 없는 인용은 나중에 맥락을 잃습니다.
- 페이지가 불확실하면 추측하지 않고 "(위치 미상)"으로 표기합니다.

## 멈추고 질문할 조건

- 사용자가 인용을 전혀 언급하지 않았을 때 → 요약에서 추출하되, "직접 기억나는 문장이 있으면 알려주세요"라는 메모를 남깁니다.
