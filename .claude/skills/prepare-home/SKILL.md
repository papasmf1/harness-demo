# 집 비우기 준비 매뉴얼

## 목적

여행 기간 동안 집과 일상이 안전하게 유지되도록, 출발 전에 반드시 확인해야 할 항목을 Clean state 목록으로 정리합니다.

**Clean state란:** 내가 떠나도 아무 문제가 없는 완전히 정돈된 상태. 돌아왔을 때 처리할 일이 쌓여 있지 않은 상태.

## 4대 필수 영역

1. **안전**: 가스, 전기, 잠금장치
2. **우편·행정**: 우편물 처리, 공과금 자동이체 확인
3. **생활**: 반려식물, 반려동물, 냉장고
4. **업무**: 부재 알림, 긴급 연락처 위임

## 절차

1. 출발일과 귀국일을 확인한다.
2. 4대 영역별 체크리스트를 작성한다.
3. 각 항목에 담당 시점을 붙인다 (D-7, D-3, D-1, 출발 당일).

## 산출물 형식

```md
## Clean state 체크리스트

### 🔒 안전 (출발 당일)
- [ ] 가스 밸브 잠금 확인
- [ ] 모든 창문·문 잠금 확인
- [ ] 불필요한 전자기기 플러그 뽑기 (냉장고 제외)
- [ ] 에어컨·난방 전원 끄기

### 📬 우편·행정 (D-7 이전)
- [ ] 우편물 수령 대행 부탁 (이웃 또는 가족)
- [ ] 공과금·구독 서비스 자동이체 잔액 확인
- [ ] 여행 기간 내 만료되는 공과금·카드 갱신 확인

### 🌱 생활 (D-3 이전)
- [ ] 반려식물 물 주기 부탁 또는 자동 급수기 설치
- [ ] 냉장고 내 유통기한 임박 식품 처리
- [ ] 쓰레기 배출 완료
- [ ] 반려동물 위탁 완료 (해당 시)

### 💼 업무 (D-7 이전)
- [ ] 이메일 자동 응답(부재 알림) 설정
- [ ] 긴급 업무 연락처 동료에게 공유
- [ ] 출발 전 마감 업무 완료 확인
- [ ] 중요 서류 디지털 사본 클라우드 저장

### 🔑 출발 당일 최종 확인
- [ ] 위 모든 항목 완료 확인
- [ ] 여권·항공권·지갑 최종 확인
- [ ] 집 열쇠 비상 연락처에 전달 (필요 시)
```

## 품질 기준

- 4대 영역(안전·우편·생활·업무)은 반드시 포함합니다.
- 각 항목에 수행 시점(D-7, D-3, D-1, 당일)을 명시합니다.
- 개인 상황에 따라 추가·제거할 수 있음을 안내합니다.
