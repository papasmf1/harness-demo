# 학습 방식 선택 매뉴얼

## 목적

같은 취미라도 독학, 학원, 온라인 강의 중 어떤 방식을 선택하느냐에 따라 비용·속도·지속성이 달라집니다. 목표와 상황에 맞는 방식을 고릅니다.

## 3가지 방식 기본 특성

| 방식 | 비용 | 피드백 | 유연성 | 동기 유지 |
|---|---|---|---|---|
| 독학 | 낮음 | 없음 | 높음 | 어려움 |
| 학원 | 높음 | 즉각적 | 낮음 | 쉬움 |
| 온라인 강의 | 중간 | 제한적 | 높음 | 중간 |

## 절차

1. `01-goal.md`에서 목표 수준, 기간, 예산, 주당 가용 시간을 파악한다.
2. 3가지 방식을 목표 기준으로 비교한다.
3. 사용자 상황(예산, 시간, 성향)에 맞는 방식을 1가지 추천한다.
4. 추천 이유와 주의 사항을 포함한다.

## 산출물 형식

```md
# [취미 이름] 학습 방식 비교

## 방식별 비교표
| 항목 | 독학 | 학원 | 온라인 강의 |
|---|---|---|---|
| 월 예상 비용 | | | |
| 피드백 | | | |
| 시간 유연성 | | | |
| 목표 달성 난이도 | | | |
| 추천 대상 | | | |

## 추천 방식: [방식 이름]

### 추천 이유
- 

### 이 방식으로 시작할 때 주의 사항
- 

### 대안 방식 (2순위)
- 방식: 
- 이유: 
```

## 품질 기준

- 3가지 방식을 모두 비교합니다. 특정 방식을 무조건 추천하지 않습니다.
- 예산 한도를 반드시 반영합니다. 예산 초과 방식은 "예산 초과" 표시를 붙입니다.
- 특정 학원 이름이나 강의 URL은 포함하지 않습니다.
