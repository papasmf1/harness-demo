# 알람 계획 수립

## 목적

도착 목표 시간에서 역산하여 기상 시간을 결정하고, 늦잠 위험을 줄이는 알람 전략을 제안합니다.

## 절차

### 1단계: 입력 확인

- 도착 목표 시간 — 필수
- 이동 시간 — 필수
- 아침 준비 예상 소요 시간 (없으면 45분으로 가정)

### 2단계: 기상 시간 역산

```
출발 시간 = 도착 목표 시간 - 이동 시간 - 여유 10분
기상 시간 = 출발 시간 - 아침 준비 소요 시간
```

### 3단계: 알람 전략 작성

- **보조 알람**: 기상 시간 - 10분 (심리적 완충)
- **주 알람**: 기상 시간
- 스누즈 금지 권고 문구 포함

### 4단계: 산출물 작성

`morning/artifacts/01-alarm.md`에 저장합니다.

## 산출물 형식

```md
# 알람 계획

> 도착 목표: [  ] | 이동 시간: [  ]분 | 준비 소요: [  ]분

## 시간 역산

| 단계 | 시간 |
|---|---|
| 도착 목표 | [  ] |
| 출발 시간 | [  ] (도착 - 이동 - 여유 10분) |
| 기상 시간 | [  ] (출발 - 준비 [  ]분) |

## 알람 설정

| 알람 | 시간 | 용도 |
|---|---|---|
| 보조 알람 | [  ] | 잠에서 깨어나기 시작 |
| 주 알람 | [  ] | 실제 기상 — 이후 스누즈 없음 |

> 권고: 주 알람 이후 스누즈를 누르면 출발 시간이 밀립니다. 보조 알람을 활용하세요.
```
