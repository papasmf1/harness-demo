# 환전 준비 매뉴얼

## 목적

최적의 환전 방법과 현지에서 안전하게 결제하는 방법을 안내합니다.

## 절차

1. 목적지 국가의 통화와 카드 사용 환경을 파악한다.
2. 환전 방법 옵션을 비교한다 (은행 환전, 공항 환전, 트래블카드, 현지 ATM).
3. 현금과 카드 비율을 권장한다.
4. 비상용 현금 규모를 안내한다.

## 환전 방법 비교 기준

| 방법 | 장점 | 단점 |
|---|---|---|
| 은행 환전 (출국 전) | 우대율 적용 가능 | 사전 신청 필요 |
| 공항 환전 | 편리 | 수수료 높음 |
| 트래블카드 (하나, 씨티 등) | 현지 ATM 출금 편리 | 사전 충전 필요 |
| 현지 ATM | 필요할 때마다 | 인출 수수료 발생 가능 |

## 산출물 형식

```md
## 환전 계획 가이드

**목적지 통화:** [통화명]
**여행 기간:** [N일]

**권장 준비 방법**
- 현금: 전체 예산의 20-30% (비상용 + 현금 선호 지역 대비)
- 카드: 해외 결제 수수료 없는 카드 1-2장
- 트래블카드: 현지 ATM 출금용으로 1장 권장

**환전 체크리스트**
- [ ] 출발 1주 전 주거래 은행 앱에서 환전 우대 신청
- [ ] 현금 비상금 최소 100달러(또는 현지 통화 동등액) 별도 보관
- [ ] 해외 결제 수수료 없는 체크/신용카드 보유 확인
- [ ] 카드 해외 사용 한도 사전 확인 및 필요 시 상향
- [ ] 현지 카드 결제 불가 지역(재래시장 등) 대비 현금 분산 보관

**주의사항**
- 공항 환전소는 수수료가 높으니 가능하면 출국 전 환전
- 현금은 여러 곳에 나눠 보관 (지갑, 가방, 숙소 보관함)
```

## 품질 기준

- 특정 은행이나 카드사를 추천하지 않습니다.
- 비상용 현금 규모 안내는 반드시 포함합니다.
- 목적지가 현금 선호 국가인지 카드 중심 국가인지 구분해서 안내합니다.
