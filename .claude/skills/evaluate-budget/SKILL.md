# 예산·품질 평가 작업 매뉴얼

## 절차

1. **입력 읽기**
   - `party/artifacts/01-ideas.md` 전체 읽기
   - 부모 원본 조건(나이, 예산, 인원, 알레르기) 확인

2. **Rubric 채점 (5개 항목)**

   **R1 — 예산 준수**
   - 각 아이디어의 예상 비용 합계 계산
   - 예산 상한의 100% 이하 → ✅, 초과 → ❌

   **R2 — 알레르기 안전**
   - 주요 메뉴에 알레르기 유발 식재료 표시 여부 확인
   - 표시 또는 제외 → ✅, 미표시 → ❌

   **R3 — 나이 적합성**
   - 모든 활동이 해당 나이에 안전하고 적합한지 확인
   - 적합 → ✅, 부적합 → ❌

   **R4 — 인원 수용**
   - 활동·장소 제안이 예상 인원을 수용할 수 있는지 확인
   - 가능 → ✅, 불가능 또는 불명확 → ⚠️

   **R5 — 테마 일관성**
   - 아이디어 3가지가 모두 선택 테마와 연결되는지 확인
   - 연결 → ✅, 1개 이상 이탈 → ⚠️

3. **판정**
   - R1 또는 R2 실패 → **FAIL** — idea-generator에 재작업 요청
   - R3 실패 → **FAIL** — idea-generator에 재작업 요청
   - R4 또는 R5만 실패 → **WARN** — 이후 단계에서 수정
   - 전체 통과 → **PASS**

4. **재작업 지시 작성**
   - FAIL 항목마다 구체적 수정 요청 1~2줄 작성

5. **파일 저장**
   - `party/artifacts/02-evaluation.md`에 저장

## 품질 체크

- [ ] 5개 Rubric 항목 모두 채점 완료
- [ ] 판정 근거가 항목별로 명시됨
- [ ] FAIL 시 idea-generator에게 전달할 구체적 수정 요청 포함
- [ ] 2회 연속 FAIL 시 → 사용자에게 조건 완화 요청
