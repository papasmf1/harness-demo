# 전날 저녁 Environment Audit

## 목적

다음 날 아침 루틴의 실패를 전날 저녁에 예방합니다. 아침의 혼란은 대부분 전날 저녁 미준비에서 시작됩니다.

## 절차

### 1단계: progress.md 확인 (있는 경우)

- `morning/progress.md`가 존재하면 읽습니다.
- 2회 이상 기록된 실패 카테고리를 파악합니다.
- 해당 항목을 체크리스트 상단 [중점 점검] 구역에 배치합니다.

### 2단계: 고정 7개 항목 점검

아래 항목을 순서대로 체크리스트에 포함합니다:

| 번호 | 항목 | 내용 |
|---|---|---|
| 1 | 내일 날씨 확인 | 기온·강수 여부 → 겉옷·우산 결정 |
| 2 | 옷 꺼내 놓기 | 상의·하의·신발 미리 준비 |
| 3 | 가방 짐 확인 | 필수 소지품 전부 넣었는지 점검 |
| 4 | 아침 식재료 확인 | 냉장고에 재료 있는지 확인 |
| 5 | 알람 설정 확인 | 주 알람 + 보조 알람 켜져 있는지 확인 |
| 6 | 기기 충전 확인 | 스마트폰·이어폰·보조배터리 충전 연결 |
| 7 | 다음 날 일정 확인 | 특이사항(회의, 과제 제출, 외출 장소) 미리 파악 |

### 3단계: 산출물 작성

`morning/artifacts/00-audit.md`에 저장합니다.

## 산출물 형식

```md
# 전날 저녁 Environment Audit

> 날짜: [작성일] | 내일 목적: [출근/등교 등]

## [중점 점검] — 반복 실패 항목

(progress.md에서 추출된 항목. 없으면 이 구역 생략)

- [ ] [반복 실패 항목 1]
- [ ] [반복 실패 항목 2]

## 기본 점검 7개 항목

- [ ] 1. 내일 날씨 확인 — 기온: [  ]°C, 비: [예/아니오]
- [ ] 2. 옷 꺼내 놓기 — 상의: [  ], 하의: [  ], 신발: [  ]
- [ ] 3. 가방 짐 확인 — [지갑 / 교통카드 / 열쇠 / 기타: [  ]]
- [ ] 4. 아침 식재료 확인 — 오늘 메뉴: [  ], 재료 있음: [예/아니오]
- [ ] 5. 알람 설정 확인 — 주 알람: [  ], 보조 알람: [  ]
- [ ] 6. 기기 충전 확인 — 폰: [  ]%, 이어폰: [예/아니오]
- [ ] 7. 내일 특이사항 — [없음 / 있으면 기록]
```

## 두께 (Thickness)

이 스킬은 **두꺼운(Thick) 스킬**입니다. 7개 항목은 고정이며 임의로 줄이지 않습니다. [중점 점검] 구역만 progress.md에 따라 유동적으로 추가됩니다.
