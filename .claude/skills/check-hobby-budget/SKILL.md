# 취미 예산 점검 매뉴얼 (Guardrail — 두꺼운 규칙)

## 목적

장비 목록의 총 예상 비용이 예산 한도를 벗어나는지 확인하고, 초과하면 구체적인 조정 방향을 제시합니다. 사용자가 충동적인 지출로 취미를 포기하지 않도록 막는 역할입니다.

## 판정 기준 (고정 규칙)

| 조건 | 판정 | 조치 |
|---|---|---|
| 총 비용 ≤ 한도 × 0.9 | **PASS** | 10% 여유 확보, 바로 진행 |
| 한도 × 0.9 < 총 비용 ≤ 한도 | **PASS with 주의** | 여유 없음 경고 후 진행 |
| 총 비용 > 한도 | **BLOCK** | 조정 제안 + gear-advisor 재작업 요청 |

## 절차

1. `03-gear.md`에서 총 예상 비용을 읽는다.
2. `01-goal.md`에서 사용자 예산 한도를 읽는다.
3. 위 기준에 따라 판정한다.
4. 결과를 `03-gear.md` 맨 아래에 추가한다.

## BLOCK 시 조정 제안 방법

아래 순서로 절감 방안을 제시합니다:
1. 선택 장비 제외 → 필수+권장만 유지
2. 권장 장비 중 나중에 사도 되는 것 제외
3. 악기 대여 또는 중고 구매 검토
4. 예산 한도 상향 검토 (마지막 옵션)

## 산출물 형식 (03-gear.md 맨 아래에 추가)

```md
---

## 예산 점검 결과

- 총 예상 비용: 원
- 예산 한도: 원
- 판정: **PASS** / **PASS with 주의** / **BLOCK**

### 판정 이유
- 

### 조정 제안 (BLOCK 시)
1. 
2. 
3. 
```

## 품질 기준

- 판정 기준 수치는 절대 임의로 바꾸지 않습니다. (0.9 배율 고정)
- BLOCK 판정 시 비판적 표현을 쓰지 않습니다. 사실과 대안만 씁니다.
- 예산 한도가 명시되지 않으면 판정하지 않고 오케스트레이터에게 요청합니다.
