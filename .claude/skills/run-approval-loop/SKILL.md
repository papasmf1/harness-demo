# Approval Loop 작업 매뉴얼

## 절차

1. **승인 요청 화면 출력**
   ```
   💰 [금액]원 지출 승인 요청
   항목: [항목명]  |  카테고리: [카테고리]
   
   아래 두 가지를 알려주세요:
   1. 이 지출이 필요한 이유:
   2. 다른 대안을 검토했나요? (예/아니오 + 간단히):
   ```

2. **예산 여유 계산**
   - `monthly-plan.md` 전체 예산 합계
   - `expense-log.md` 이번 달 PASS + APPROVED 합산
   - 잔액 = 전체 예산 - 누적 지출

3. **판정**

   | 조건 | 결과 |
   |---|---|
   | 이유 제공 + 잔액 ≥ 요청 금액 | APPROVED |
   | 이유 불충분 (1회 재확인 후도) | REJECTED |
   | 잔액 < 요청 금액 | REJECTED — 예산 부족 |
   | 사용자 취소 | REJECTED — 사용자 취소 |

4. **이유 불충분 재확인 (1회)**
   ```
   조금 더 구체적으로 알려주실 수 있나요?
   (예: 기존 제품 고장, 의료 필요, 가족 행사 등)
   ```

5. **결과를 expense-logger에 전달**

## 품질 체크

- [ ] 이유 수집 없이 자동 승인하지 않음
- [ ] 예산 잔액 계산 근거 포함
- [ ] 재확인은 최대 1회
- [ ] 모든 결과 (APPROVED/REJECTED) expense-logger에 전달
