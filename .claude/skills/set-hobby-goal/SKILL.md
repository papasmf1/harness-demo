# 취미 목표 설정 매뉴얼

## 목적

"기타 배우고 싶다"처럼 막연한 바람을 6개월 후에 달성 여부를 확인할 수 있는 구체적인 목표로 바꿉니다.

## SMART 기준

| 항목 | 의미 | 기타 예시 |
|---|---|---|
| Specific (구체) | 무엇을 할 것인지 | 팝송 1곡을 처음부터 끝까지 |
| Measurable (측정) | 어떻게 확인할 것인지 | 반주 없이 혼자 연주 |
| Achievable (달성) | 현실적인지 | 6개월, 주 3회 연습 기준 |
| Relevant (관련) | 왜 하려는지 | 오랫동안 하고 싶었던 취미 |
| Time-bound (기한) | 언제까지 | 6개월 후 |

## 절차

1. 취미 종류, 기간, 기대 수준, 주당 가용 시간을 확인한다.
2. 정보가 없으면 "미정"으로 표시하고 오케스트레이터에게 보완 요청.
3. SMART 5개 항목을 채워 목표 문서를 작성한다.
4. 목표가 비현실적이면 조정 제안을 별도 섹션에 포함한다.

## SMART 분석

## 품질 기준

- SMART 5개 항목은 모두 채웁니다. 모르는 항목은 "확인 필요"로 표시합니다.
- 마일스톤은 초보자 기준으로 현실적인 수준으로 씁니다.
- "잘 치고 싶다"처럼 측정 불가능한 표현은 측정 가능하게 바꿉니다.
