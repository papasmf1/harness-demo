## 환전 계획 가이드

**목적지 통화:** 베트남 동 (VND)
**여행 기간:** 16박 17일 (2026-05-20 ~ 2026-06-05)
**총 예산:** 250만원

---

### 다낭 현지 결제 환경

다낭은 **현금(VND) 선호 도시**입니다.

- 대형 쇼핑몰(빈콤플라자)·관광지 레스토랑·호텔: 카드 결제 가능
- 현지 식당(로컬 쌀국수집·껌빈전)·재래시장(한시장·꽁비엔시장)·노점·쌤쏭(오토바이 택시): **현금 필수**
- 그랩(Grab) 앱 결제: 카드 또는 현금 모두 가능
- 환율 기준: 1만원 ≈ 약 185,000~190,000 VND (출발 전 최신 환율 재확인)

### 권장 준비 방법

| 수단 | 비율 | 용도 |
|------|------|------|
| 현금 (VND 환전) | 전체 현지 경비의 **50~60%** | 로컬 식당·시장·교통·소규모 결제 |
| 해외 수수료 없는 체크/신용카드 | 전체 현지 경비의 **30~40%** | 대형 마트·호텔·관광 예약 결제 |
| 트래블카드 (비상 ATM 출금용) | 비상 현금 출금용 1장 | 현금 부족 시 현지 ATM 사용 |

> **현금 비율이 높은 이유:** 다낭 로컬 여행 특성상 현금 사용 빈도가 높습니다. 특히 오토바이 렌탈비·현지 마사지·길거리 음식은 현금 전용입니다.

### 환전 방법 비교 및 권장

| 방법 | 장점 | 단점 | 권장 여부 |
|------|------|------|-----------|
| 은행 앱 사전 환전 (출국 전) | 우대율 최대 적용 | VND 취급 은행 제한적 | **1순위 권장** |
| 공항 환전 (인천 출국장) | 편리 | 수수료 높음, VND 소액권 부족 가능 | 보조 수단 |
| 트래블카드 (현지 ATM 출금) | 필요할 때 소액 출금 | 인출 수수료 발생 가능 | **비상용 권장** |
| 현지 환전소 (다낭) | 환율 유리한 곳 존재 | 위조지폐·사기 위험 | 신뢰 가게에서만 |

> VND는 국내 취급 은행이 제한적입니다. 출발 전 주거래 은행 앱에서 VND 환전 가능 여부 먼저 확인하세요.

### 환전 체크리스트

**출발 전 (D-13~D-7)**

- [ ] 출발 **1주 전** 주거래 은행 앱에서 VND 환전 우대 신청 (50~90% 우대율 적용)
- [ ] VND 환전 불가 시: USD로 환전 후 다낭 현지 환전소에서 VND 교환 (USD → VND 환율 유리)
- [ ] 트래블카드 발급 또는 충전 완료 (비상 ATM 출금용 — 특정 카드 추천 없음)
- [ ] 보유 신용/체크카드 해외 결제 수수료 확인 (수수료 없는 카드 우선 사용)
- [ ] 카드 해외 사용 한도 확인 및 필요 시 상향 신청

**현금 보관 방법**

- [ ] 현금은 3곳으로 분산 보관: 지갑(소액) / 보조 가방(중간 금액) / 숙소 세이프티박스(비상금)
- [ ] 비상금 20만원 상당 VND는 숙소 보관함에 분리 보관 — 절대 평상시 사용 자제
- [ ] 소액권(1만 동, 2만 동, 5만 동) 다수 준비 — 시장·로컬 식당 거스름돈 문제 방지

**현지에서**

- [ ] ATM 이용 시 은행 공식 ATM(Vietcombank, BIDV 등) 우선 이용 — 사설 ATM 수수료 높음
- [ ] 카드 결제 시 VND 결제 선택 (원화 결제 DCC 옵션 거절 — 환율 불리)
- [ ] 대형 결제(숙소 정산, 투어 비용) 전 카드 한도 여유분 사전 확인

**주의사항**
- 공항 환전소는 수수료가 높으므로 가능하면 출국 전 은행에서 환전
- 다낭 한시장(Han Market) 주변 환전소는 환율이 유리한 곳이 있으나, 영수증 확인 필수
- VND는 고액권(50만 동)과 저액권(1만 동)의 색상이 유사해 혼동 주의 — 거래 전 금액 재확인
- 현금은 여러 곳에 나눠 보관하고, 한 번에 많은 현금을 꺼내는 행동 자제

## 예산 배분 계획

**총 예산: 250만원**

| 항목 | 예산 범위 | 메모 |
|------|-----------|------|
| 항공권 (왕복) | 40~60만원 | LCC 기준 수하물 포함 가격 확인 필수 |
| 숙소 (16박) | 48~80만원 | 1박 3~5만원 × 16박 / 연박 할인 협의 권장 |
| 식비 (17일) | 68~85만원 | 1일 4~5만원 (로컬 식당 중심 절감 가능) |
| 교통 | 15~25만원 | 그랩·오토바이 렌탈·시내버스 조합 |
| 관광·액티비티 | 30~40만원 | 바나산·호이안 당일치기·해양 스포츠 등 |
| 쇼핑·기타 | 20~30만원 | 기념품·마사지·예비 잡비 |
| 비상금 | 20만원 | 현금 별도 보관 — 절대 사용하지 않는 것 목표 |
| **합계 (범위)** | **241~340만원** | — |

> **핵심 포인트:** 합계 하단(241만원)은 250만원 예산 내 충분히 소화 가능하나, 상단(340만원)은 **90만원 초과**입니다. **항공권과 숙소를 각각 하단 범위로 절감하는 것이 예산 관리의 핵심**입니다.
>
> - 항공권 목표: **50만원 이하** (LCC 조기 예약, 수하물 포함가 비교)
> - 숙소 목표: **60만원 이하** (1박 약 3.7만원 × 16박 / 연박 할인 협의 적극 활용)
> - **항공+숙소 합계를 110만원 이하로 맞추면** 나머지 예산 140만원으로 현지 경비(식비·교통·관광·쇼핑·비상금) 충당 가능
