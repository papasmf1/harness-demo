## 수하물 규정 요약

| 구분 | 규정 |
|------|------|
| 기내 수하물 | **7kg** (저가항공 LCC 기준) |
| 위탁 수하물 | **20kg** (유료 추가 구매) |
| 보조배터리 | 기내 수하물 **필수** (위탁 반입 불가) |
| 액체류 기내 반입 | **100ml 이하 + 지퍼백 1개** |
| 베트남 콘센트 | **A타입** — 한국 플러그 그대로 사용 가능, **별도 어댑터 불필요** |

> **전략**: 16박 기준 세탁 2~3회 전제로 의류를 최적화합니다.
> 보조배터리·여권·현금 등 귀중품과 리튬배터리는 **기내 수하물 필수**.
> 세면도구·선크림 대용량·해변 용품은 위탁 수하물에 담고, 가능하면 현지 구매로 무게를 절약합니다.

### 전자기기 (리튬배터리 기내 필수)

- [ ] 스마트폰 + 충전 케이블
- [ ] 보조배터리 (리튬배터리 — **위탁 불가, 기내만 가능**)
- [ ] 이어폰 / 무선 이어버드
- [ ] 스마트워치 (착용 또는 기내 가방)

- [ ] 안대
- [ ] 이어플러그
- [ ] 간식 (저가항공 기내식 별도 구매 기준)

### 액체류 기내 반입 (100ml 이하, 지퍼백 1개)

- [ ] 선크림 소형 튜브 (100ml 이하) — 5~6월 강한 자외선 필수

## 위탁 수하물 (또는 기내 가방 여유 시 통합)

### 의류 — 5월 하순~6월 초 다낭: 기온 26~36도, 강한 자외선, 건기 끝물

> **세탁 전제**: 약 5~6일 간격으로 2~3회 코인세탁소·숙소 세탁기 이용.
> 속옷·양말은 넉넉히, 외의는 최소화합니다.

**상의**

- [ ] 반팔 티셔츠 8벌 (면·린넨 소재 권장 — 고온다습, 통기성 필수)
- [ ] 얇은 긴팔 셔츠 1벌 (강한 냉방 식당·쇼핑몰·실내 관광지 대비)

**하의**

- [ ] 반바지 3벌
- [ ] 얇은 긴바지 1벌 (호이안 사원·종교 시설 방문 시 필수 복장)

**속옷·양말**

- [ ] 속옷 9벌
- [ ] 양말 5켤레 (해변·숙소에서는 샌들·맨발)

**잠옷·수면용**

- [ ] 얇은 잠옷 또는 반팔+반바지 세트 1벌

**수영·해변**

- [ ] 수영복 2벌 (미케비치 등 해변 활동, 수상 스포츠 필수)
- [ ] 래시가드 1벌 (5~6월 자외선 지수 매우 높음 — 피부 보호 필수)
- [ ] 비치타월 1장 (숙소 제공 여부 확인 후 생략 또는 현지 구매 대체 가능)

**신발·액세서리**

- [ ] 편한 운동화 1켤레 (호이안·바나힐 당일치기·관광)
- [ ] 샌들 또는 슬리퍼 1켤레 (해변·숙소·시내 이동)
- [ ] 선글라스 (5~6월 자외선 강함 — 필수)
- [ ] 챙 넓은 모자 (버킷햇 또는 캡 — 자외선 차단·열사병 예방)

- [ ] 물티슈 (현지 외출·식사 시 활용도 높음)

## 현지 구매 권장 항목

> 짐 무게를 줄이기 위해 다낭 현지(한시장·빅씨마트·롯데마트 다낭점)에서 도착 당일 구매를 권장합니다.

- 샴푸·바디워시·치약 (현지 마트 매우 저렴)
- 선크림 추가분 (한국 브랜드 판매 多, 가격도 합리적)
- 생수 (숙소·편의점, 수돗물 직접 음용 금지)
- 모기 기피제 (현지 제품 효과 우수)
- 과일·간식

## 기내 7kg 절약 전략

> 저가항공 기내 수하물 7kg 한도 내에서 여행하거나 위탁 20kg을 최소화하는 전략입니다.

1. **의류 최소화**: 세탁 2~3회 전제로 반팔 8벌·반바지 3벌이면 16박 충분.
2. **세면도구 현지 구매**: 샴푸·바디워시·치약·모기 기피제는 도착 후 마트 구매.
3. **선크림 분리**: 100ml 이하 소형 1개는 기내 지퍼백, 대용량은 위탁 수하물.
4. **신발 최소화**: 운동화 1켤레(착용) + 샌들 1켤레만 — 위탁 가방 공간 절약.
5. **책·종이류 제외**: 전자책(킨들·앱) 활용, 종이 가이드북 생략.
6. **비치타월 생략**: 숙소 제공 확인 후 없으면 현지 구매(저렴).
7. **무거운 화장품 제외**: 스킨·로션은 여행용 소분 용기 또는 현지 구매.
