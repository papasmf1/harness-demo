## 파티 개요

### 아이디어 선택 안내

부모가 파티 성격에 맞게 아래 두 가지 방향 중 하나를 선택하거나 조합할 수 있습니다.

| | 아이디어 1: 공룡 발굴 탐험대 | 아이디어 2: 쥬라기 탐험 캠프 |
|---|---|---|
| 핵심 분위기 | STEM 체험 · 탐구 · 발견 | 어드벤처 · 팀 경쟁 · 활동적 |
| 주요 활동 | 화석 발굴 대회, 공룡 뼈 조립, 공룡 퀴즈 빙고 | 공룡알 보물찾기, 줄다리기 릴레이, 피규어 페인팅 |
| 케이크 | 홈메이드 공룡 발자국 케이크 | 주문 공룡 캐릭터 케이크 |
| 기념품 | 조립한 공룡 뼈 세트 | 직접 채색한 공룡 피규어 |
| 예상 비용 | 약 13.2만원 | 약 18.7만원 |
| 추천 대상 | 과학·탐구를 좋아하는 아이 | 몸으로 뛰는 활동을 좋아하는 아이 |

### 공통 콘셉트

- 공룡 테마를 음식·장식·활동 전체에 일관되게 적용
- 10세 눈높이의 규칙 기반 게임으로 성취감과 경쟁심 자극
- 각자 완성물(조립 세트 또는 피규어)을 집에 가져가는 기억 남는 결말

## 음식 요약

### 케이크

- 아이디어 1: 홈메이드 공룡 발자국 케이크 (초록 버터크림 + 초코 발자국, 재료비 약 1.5만원)
- 아이디어 2: 주문 공룡 캐릭터 케이크 (티라노사우루스 피규어 토퍼, 약 6만원 / D-7 주문 필수)

### 핑거푸드

| 메뉴 | 설명 |
|---|---|
| 공룡알 미트볼 | 냉동 미트볼 + 이쑤시개 + '공룡알' 팻말 |
| 공룡 발자국 샌드위치 | 식빵을 공룡발 커터로 잘라 햄+치즈 샌드위치 |
| 티라노 이빨 치킨 너겟 | 시판 냉동 너겟 + 마요 딥 + '티라노 이빨' 팻말 |
| 공룡 나무 채소 스틱 | 브로콜리·당근·오이 스틱 + 허머스 딥 |
| 초코 바나나 공룡 뼈 꼬치 | 바나나 + 초코 펜으로 뼈 모양 그려 꼬치에 꽂기 |

### 음료

| 메뉴 | 설명 |
|---|---|
| 늪 음료 | 탄산수 + 레몬즙 + 민트 시럽 (녹색빛) |
| 공룡 바다 | 사과주스 + 블루 시럽 (투명 컵에 담아 시각 효과) |
| 생수·탄산수 | 예비용 |
